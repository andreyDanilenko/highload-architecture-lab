# AGENTS.md — контекст для AI-агентов

Это учебная лаборатория Go, distributed systems, паттернов и декомпозиции. Качество подтверждается понятным кодом, явными ограничениями и воспроизводимыми экспериментами.

Перед работой прочитать [CONTRIBUTING.md](CONTRIBUTING.md) — единый источник правил участников. Затем README и `docs/experiment-notes.md` затронутой задачи, если они существуют.

## Обязательные правила

- Сохранять пользовательские изменения и намеренно ошибочные baseline-варианты, явно отмечая их ограничения.
- Выбирать минимальную понятную структуру; паттерн не требует отдельного сервиса. В shared выносить устойчивые технические механизмы, не предметные правила.
- Комментировать значимые шаги, причины решений и границы гарантий. Следовать языку общения и соглашениям задачи.
- При создании или существенном изменении задачи поддерживать `docs/experiment-notes.md` по [шаблону](docs/experiment-template.md): гипотеза, условия, результат, границы, контрпример, вопросы.
- Не выдумывать результаты запусков и понимание учащегося. Разделять черновик AI, факты проверки и человеческую рефлексию; пустые поля допустимы.
- После изменений выполнять соразмерные проверки из CONTRIBUTING и сообщать их фактический результат.
- Не создавать commit/push и не отправлять сообщения третьим лицам без явного поручения; учитывать уже выданное пользователем разрешение.

## Навигация по материалам

- [Материалы 01–30](docs/reading-map-01-30.md): статьи, документация и исходный код; [оценка постановок](docs/quality-review-01-30.md).
- [EventLab и мастерские 01–107](docs/project-playground-01-107.md): возможные связи экспериментов, без обязательного общего приложения или последовательности. Для прикладных задач с 05 исходный сценарий — мероприятия и билеты.
- При объяснении кода следовать разделу CONTRIBUTING «Исследование кода и связанные проекты»: небольшой фрагмент, одна ветка, конкретный вход и переход. Не повторять наставления о самостоятельном обучении.
