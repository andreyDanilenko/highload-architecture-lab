# Карта изучения Go

Карта связывает свойства языка с опытами лаборатории. Наличие Go-реализации задачи не означает, что все связанные темы освоены. Выбирать одну-две темы на опыт и ссылаться на их ID из `docs/experiment-notes.md`. Привязки ниже предлагают места для опыта, а не утверждают, что соответствующая возможность уже реализована в каждой задаче.

Это ориентир для последовательного исследования, а не обещание полного знания языка. Сложные ветви можно подключать по вопросу, который возник в задаче.

| ID | Тема | Где удобно исследовать | Небольшой проверяемый опыт |
|----|------|-----------------------|----------------------------|
| GO-01 | Значения, указатели, arrays/slices/maps, aliasing | 01 остатки, 06 кэш | Предсказать изменение через общий backing array; сравнить с копией и объяснить владение |
| GO-02 | Interfaces, method sets, typed nil, embedding | 02 anti-bruteforce, 04 idempotency | Заменить provider без изменения вызывающего кода; воспроизвести typed-nil ошибку |
| GO-03 | Ошибки, wrapping, `errors.Is/As`, `defer`, panic/recover | 04 idempotency, 08 gateway | Проследить ошибку через слои и проверить освобождение ресурса при раннем выходе |
| GO-04 | Goroutines, channels, `select`, mutex/atomic, memory model | 01 остатки, 03 pool | Нарушить синхронизацию, найти race, объяснить happens-before и пределы проверки race detector |
| GO-05 | `context`, deadlines, отмена и жизненный цикл goroutine | 03 pool, 08 gateway, 23 scheduler | Отменить запрос во время работы; проверить завершение фоновой работы и владельца отмены |
| GO-06 | `io.Reader/Writer`, partial reads, EOF, буферы и streaming | 25 proxy, 26 file server, 27 parser | Подать сообщение кусками и воспроизвести частичную запись; проверить границы буфера |
| GO-07 | HTTP, sockets, connection reuse, deadlines, half-close | 07 BFF, 08 gateway, 25 proxy | Замедлить клиента/зависимость, измерить соединения и проверить остановку запроса |
| GO-08 | Generics, constraints, type inference, reflection | 06 кэш, 27 сериализация | Сравнить небольшой generic-контейнер с конкретным типом; объяснить цену выбранного контракта |
| GO-09 | Allocations, escape analysis, GC, stack/heap | 06 кэш, 26 streaming, 59 runtime | Найти выделения профилем, изменить одну причину и сравнить память, паузы и время |

| GO-11 | Tests, race detector, fuzzing, benchmarks, pprof/trace | Во всех задачах по вопросу опыта | Найти контрпример тестом или fuzzing; сравнить baseline при одинаковых условиях |
| GO-12 | ABI, syscall, cgo, `unsafe`, assembly | 49 TCP/IP stack, 59 Go runtime, 102 debugger | Проследить один вызов до системной границы; записать ограничения платформы и владения памятью |

GO-12 — дополнительная ветвь, когда высокоуровневых средств недостаточно для ответа на вопрос. `unsafe` и cgo не являются обязательными средствами оптимизации. Во всех темах проверять детали по документации установленной версии Go и сохранять ссылку на использованный источник.

## Как отмечать продвижение

В записной книжке хранить свидетельства, а не общий процент «знания Go»:

| Свидетельство | Что можно записать |
|---------------|-------------------|
| Объяснил | Собственное объяснение механизма и его границ |
| Предсказал | Прогноз до запуска и сравнение с результатом |
| Сломал и разобрал | Контрпример, диагностика и причина сбоя |
| Перенёс | Применение механизма к другой задаче или ограничению |

Один опыт может дать только одно из этих свидетельств. AI может связать существующую запись с темой карты, но не объявляет понимание человека без его объяснения. Если знания пока не проверялись, так и записать.

## Повторяющиеся вопросы

При чтении сгенерированного или чужого кода выбрать подходящие вопросы:

- Кто владеет состоянием и кто может его менять?
- Что копируется, а что ссылается на общую память?
- Когда прекращается работа и кто освобождает ресурс?
- Какая операция атомарна и в какой области?
- Что происходит при частичном успехе, повторе или отмене?
- Как измерение отделяет причину от совпадения?

Не обязательно отвечать на всё сразу. Неясный ответ становится вопросом следующего опыта по [шаблону записной книжки](experiment-template.md).
