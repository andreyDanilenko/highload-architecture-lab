# Шаблон записной книжки задачи

Создать в задаче `docs/experiment-notes.md`. Скопировать блок ниже, заменить поля в угловых скобках и добавлять новые опыты отдельными записями. Поля без данных оставить с пометкой «не заполнено» или «не запускалось». Короткому опыту достаточно нескольких предложений и ссылки на результат.

Факты запуска записывает тот, кто его выполнил. AI может подготовить гипотезу и объяснение, отмечая их как черновик. Личный прогноз и рефлексию учащийся пишет сам; согласованную редактуру пометить отдельно. Текст шаблона не означает, что опыт уже проведён.
